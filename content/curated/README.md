# Курируемая библиотека

Здесь лежат темы, ролики по которым **проверены человеком**. Это не кэш: автокэш
хранит то, что модель выдала и что случайно спросили дважды, а сюда попадает
только то, что кто-то посмотрел целиком и принял. Отсюда все правила ниже.

Чем curated отличается от автокэша:

| | Автокэш | Curated |
|---|---|---|
| Кто одобрил | никто | человек посмотрел |
| Где живёт скрипт | в БД, перегенерируется | здесь, в git |
| Срок жизни | TTL 48 ч / 30 дней | не удаляется никогда |
| При смене `PIPELINE_VERSION` | пропадает | переезжает без перерендера |

## Один скрипт на три языка

Ключевое: **на тему один `scene.py`, а не три.** Анимация от языка не зависит —
что куда летит, какие стрелки, какие оси. Меняются только надписи, и они вынесены
в `strings.<lang>.yaml`.

Что это даёт при проверке: **анимацию смотришь один раз**, дальше по каждому языку
только вычитываешь текст. Три языка стоят примерно 1.4 просмотра, а не три. И
правка анимации автоматически прилетает во все языки.

Поэтому в `scene.py` **не должно быть ни одной надписи**. Строка, написанная прямо
в скрипте, покажется во всех трёх языках сразу — тест это ловит и роняет сборку.

## Структура темы

```
content/curated/<предмет>/<тема>/
├── topic.yaml          # id, языки, синонимы вопроса, запись о проверке
├── scene.py            # анимация; все строки — через S["ключ"]
├── strings.kk.yaml     # надписи на экране
├── strings.ru.yaml
├── strings.en.yaml
├── text.kk.md          # объяснение в чат (educator_text)
├── text.ru.md
└── text.en.md
```

`scene.py` содержит ровно одну строку-маркер, которую сидер заменяет словарём
нужного языка:

```python
S = {}  # anyq:strings
```

## Как добавить тему

1. **Черновик.** Прогони вопрос обычным конвейером, возьми получившийся скрипт
   как основу. Вынеси все строки в `strings.*.yaml`, оставь в скрипте `S["ключ"]`.

2. **Проверь структуру** — это бесплатно и ловит опечатки до рендера:

   ```bash
   python scripts/seed_library.py --check
   ```

   Проверяется: наборы ключей во всех языках совпадают, каждый `S["..."]` из
   скрипта существует, в скрипте нет зашитых надписей, у каждого языка есть
   синонимы и непустой текст.

3. **Отрендерь для просмотра.** Одобрить ролик, которого ещё нет, невозможно,
   поэтому есть отдельный режим — рендерит всё, не публикует ничего:

   ```bash
   python scripts/seed_library.py --preview --topic physics.gravity_basics
   ```

   Скрипт напечатает ссылки. Смотреть нужно **залогиненным** — `/media` закрыт
   авторизацией, как и весь сервис.

4. **Одобри.** Посмотрел анимацию — ставишь `animation.approved: true`. Вычитал
   казахский текст — `kk.approved: true`. И так по языкам. Неодобренный язык не
   рендерится и не публикуется; вопрос на нём идёт обычным конвейером, как будто
   темы здесь нет.

   ⚠️ Если анимация не одобрена, не публикуется **ни один** язык: подписи лежат
   поверх общей анимации, и кривая анимация кривая на всех языках.

5. **Публикуй:**

   ```bash
   python scripts/seed_library.py
   ```

   Рендерит одобренные языки в 1080p60, регистрирует в библиотеке как `curated`,
   по одной записи на каждый синоним.

## Синонимы (`aliases`)

Каждый синоним проходит **тот же нормализатор**, что и вопрос пользователя, —
регистр, пунктуация, «объясни …» и «пожалуйста» уже отбрасываются. Поэтому
перечисляй разные формулировки, а не варианты одной:

```yaml
ru:
  - "что такое гравитация"      # да
  - "что такое сила тяжести"    # да, другая формулировка
  - "Что такое гравитация?"     # нет, это то же самое после нормализации
```

Синоним, удалённый отсюда, при следующей публикации перестаёт находиться —
сидер убирает записи, которых больше нет в `topic.yaml`.

Синоним, который нормализуется в пустую строку (например, одно «объясни»),
не публикуется, и сидер об этом скажет.

## Повторная публикация

- **Поменялся `PIPELINE_VERSION`** (промпты, модель, рендерер) — ключи кэша
  другие, но ролик тот же. `python scripts/seed_library.py` переиспользует
  существующий файл и просто перерегистрирует его под новым ключом. Рендер не
  нужен: скрипт заморожен в git.
- **Поменялся сам `scene.py` или строки** — нужен `--rerender`.

## Волнами, а не сразу

Ограничитель — не диск, а часы проверяющего. 200 тем × 3 языка это ~1.8 ГБ,
меньше 10 % бюджета в 20 ГБ. Так что curated можно наращивать спокойно: диск
кончится от автокэша, который и вытесняется.

- **Волна 1:** 25–30 самых очевидных тем программы.
- **Дальше:** только по статистике `GET /api/admin/cache/stats` — что реально
  спрашивают. Не проверять вслепую то, что никто не спросит.
