# Старый фронт

Это `frontend/src` до Ф0 — интерфейс, который работал с бэкендом по-настоящему.
Новый UI из `Hollyz812/anyq` красивее и полнее, но он не видел сервера ни разу:
у него нет ни WebSocket, ни fetch, ни плеера видео. Всё это лежит здесь.

Каталог **не собирается и не проверяется**: он исключён из `tsconfig.json`
(`include: ["src", "vite.config.ts"]`), из `.eslintrc.cjs` и из `.dockerignore`.
Импортировать отсюда напрямую нельзя — файл переносится в `src/`, а не
подключается на месте, потому что стили здесь написаны классами Tailwind,
а Tailwind в проекте больше нет.

## Что откуда брать

| Нужно | Файл |
| --- | --- |
| Плеер mp4, разметка, шкала | `features/player/VideoPlayer.tsx` |
| Слой аннотаций поверх видео | `features/player/AnnotationCanvas.tsx` |
| Панель экспорта (gif, клип, кадр, pptx) | `features/player/ExportPanel.tsx`, `useExportJob.ts` |
| Переключатель озвучки и выбор голоса | `components/NarrationToggle.tsx` |
| Клиент WebSocket с переподключением | `hooks/useWebSocket.ts` |
| Вход, регистрация, сессия по куке | `hooks/useApi.ts`, `components/LoginScreen.tsx` |
| Markdown с формулами через KaTeX | `components/MarkdownMessage.tsx` |
| Остаток квоты | `useQuota.ts` |
| Форма контракта сокета | `types.ts` |

Порядок переноса — Ф2 в плане стыковки. Каждый файл при переносе переодевается
из классов Tailwind в переменные из `src/styles/tokens.css`.

Удалить каталог можно, когда из таблицы выше не останется ни одной строки.
До этого момента он нужен: это единственное место, где записано, как именно
интерфейс разговаривал с сервером.
